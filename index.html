About Apex Telemetry

Apex Telemetry is a browser-based Formula 1 telemetry lab. It reads historical session data straight from the OpenF1 API and turns it into speed, throttle, brake, RPM and gear traces, driver comparisons and track layouts.

Every number shown comes from an OpenF1 response. When a value is missing the interface says Data unavailable instead of filling the gap.

OpenF1 is an independent, unofficial project and is not affiliated with Formula 1. The free tier allows 3 requests per second and 30 per minute, so responses are cached in your browser and loaded only when you ask for them.
